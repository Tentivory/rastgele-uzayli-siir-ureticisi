# 🛸 RASTGELE UZAYLI ŞİİR ÜRETİCİSİ 🛸

## DİKKAT: BU YAZILIM EVRENİN EN CİDDİ PROJESİDİR

Sevgili dünya vatandaşları, galaktik turistler ve rastgele geçen kara delikler,

Bu repository, **insanlık tarihinin en önemli bilimsel atılımını** içermektedir.  
Artık uzaylılarla iletişim kurmak için yıllarca dil öğrenmenize gerek yok.  
Sadece bu scripti çalıştırın ve **otomatik olarak anlamsız ama derin** şiirler üretin.

### Nasıl Kullanılır?
```bash
python uzayli_siir.py          # 3 şiir üretir
python uzayli_siir.py 7        # 7 şiir üretir (aşırı doz)
```
